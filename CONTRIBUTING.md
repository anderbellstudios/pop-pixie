# Contributing

Most contributions to Pop Pixie are made by our core team. If you're interested in becoming part of the team, please reach out to us on [Discord](https://discord.gg/5fHpe4S).

If you'd like to make a one-time contribution to Pop Pixie without joining the team, please review the following guidance for what kind of changes we're likely to accept.

## AI policy

We do not accept any AI-generated content whatsoever. This includes text, images, sounds, newly added code and changes to existing code.

## Bug fixes

If you've found a bug in Pop Pixie, please start by opening an issue. We'll determine whether the behaviour is intended and, if not, what the correct behaviour should be. If you're interested in fixing the problem yourself, please say so in the issue description.

In cases where the correct behaviour is obvious, such as crashes or typos, feel free to open a pull request immediately without creating an issue first.

## Other changes

Before opening a pull request for any changes more substantial than bug fixes, please create a discussion on GitHub or message us on Discord to discuss the changes first.

Here are some examples of the kind of suggestions we're open to receiving. We'll review each idea individually to decide whether we want to include it.

- Minor gameplay adjustments
- Improvements to existing features
- New configuration options to make the game run better on players' devices
- Accessibility options to make the game easier to play for a wider range of people

Larger changes, like new weapons, gameplay mechanics, enemies or levels, are less likely to be accepted, since these decisions are typically made internally by our core team, but we're happy to hear your idea just in case.

By submitting your ideas to us, you agree to license your ideas under the terms of Pop Pixie's [contributor license agreement](https://gist.github.com/12joan/3b83088f74aed90de821d513fea877cd).
